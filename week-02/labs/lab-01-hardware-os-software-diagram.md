### Analysis Question 3

Explain, in your own words, why a cybersecurity professional needs to understand all three layers — hardware, OS, and software — rather than just the software layer where most visible attacks (like phishing emails) happen.

```
A cybersecurity professional needs to understand all three layers from hardware, the operating system, and the software. Different layers would present different types of attacks; therefore, being able to identify a problem and the potential layer it may exist at is crucial. All of the layers are interconnected so if something happened on one layer it may affect another. For example, a user can download a file (software layer) that has malware, which can then affect the operating system. You also have attacks that can affect the memory (hardware).
```
