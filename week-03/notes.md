## In My Own Words

**What's the difference between a file and a folder, and how do they form a tree together?**

```
A folder is the container in which an individual or multiple documents(files) are stored. The folders are like the branches, and the files are like the leaves to a tree.
```

**How does a Windows-style file path differ from a Linux-style file path?**

```
A Windows-style file path starts with the root c:\ and has back slashes. The Linux-style file path has one root which is the forward slash and that's the main divider between each folder in the address path (/).
```
